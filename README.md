# Oath & Banner — 맹세와 깃발

삼국지 장수를 **등용(수집)**하고, **주장·부장·참모** 3인 부대를 조합해 **시너지 연쇄 전법**으로 싸우는 가벼운 웹 덱빌딩 전략 게임 (MVP)

- 플레이: https://jinmo78.github.io/ThreeKingdoms/
- 외부 이미지 없음 — SVG · CSS 도형 · 이모지 · lucide 아이콘만 사용
- 진행 상황은 브라우저 `localStorage`에 자동 저장 (키: `oath-banner-save`)

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 타입 체크 + 프로덕션 빌드 (dist/)
```

`main` 브랜치에 푸시하면 GitHub Actions가 GitHub Pages로 자동 배포합니다.

## 폴더 구조
```
src/
├─ types.ts                # 장수·전법·부대·스테이지 타입
├─ config.ts               # 게임 타이틀
├─ data/
│  ├─ generals.json        # 장수 28명 + 적 전용 장수 (세력/등급/병과/스탯/전법/인연)
│  ├─ bonds.ts             # 인연 10종과 단계별 보너스
│  ├─ stages.ts            # 4장 × 3스테이지 (황건적의 난 → 반동탁 연합 → 관도대전 → 적벽대전)
│  └─ meta.ts              # 세력 색상, 등급 스타일, 병과 상성
├─ engine/
│  ├─ synergy.ts           # 시너지 계산 (세력 결속 · 병과 통일 · 인연 · 명참모)
│  ├─ unit.ts              # 슬롯 가중치로 부대 능력치 산출, 레벨/돌파 보정
│  ├─ battle.ts            # 행동 게이지 자동 전투 + 연쇄 전법 (시드 고정 난수)
│  └─ gacha.ts             # 등용 확률 (SSR 5% · SR 25% · R 70%, 10연 SR 확정)
├─ store/gameStore.ts      # Zustand + persist — 금화·보유 장수·편성·진행도
├─ components/             # 장수 토큰/카드, 시너지 배지, 공용 UI
└─ pages/                  # TitleScreen · Campaign · Formation · Recruit · Roster · Battle
```

## 규칙 요약
| 항목 | 내용 |
|---|---|
| 부대 | 최대 3부대, 부대마다 주장 1 + 부장 1 + 참모 1 (주장만 있어도 출진 가능) |
| 슬롯 역할 | 주장: 부대 병과·주 전법, 무력·통솔 크게 반영 / 부장: 연쇄 1단 / 참모: 지력 크게 반영, 전법 발동률·연쇄 2단 |
| 병과 상성 | 🐎기병 > 🏹궁병 > 🛡️보병 > 🐎기병 (우위 ×1.25, 열세 ×0.8) |
| 시너지 | 같은 세력 2/3명, 주장과 같은 병과 2/3명, 인연 태그 2/3명, 지력 90 이상 참모 → 전투력 배율과 연쇄 확률 상승 |
| 연쇄 | 주장 전법 발동 → 연쇄 확률로 부장 전법 → 그 확률의 60%로 참모 전법 (기본 15%, 최대 85%) |
| 성장 | 출진 장수 전원에게 경험치, 레벨당 능력치 +4%. 중복 등용 시 돌파 ★ (+4%, 최대 ★5) |
