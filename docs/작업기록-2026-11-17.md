공성 · 전술 · 내정 · (예정) AI 군주/비동기 대전으로 개편하는 로드맵을 잡았다.
선택: 핵심=공성·전술·멀티·도시·PvP, 규모=크게, 1단계부터, 스테이지는 성으로 대체.
1~4단계는 완료·배포. 상세 규칙은 `CLAUDE.md`의 '공성' 절 참고.

- **출정 버튼**: `Briefing`(`Campaign.tsx`)에서 제목 바로 아래 고정 영역으로 이동. 아래 내용만 스크롤됨
- **영지 문구**: `DomainBar`를 "점령한 성 N곳 · 1시간에 X금 생산" / 버튼 "금화 받기 N"으로 (모든 성에 쌓인 금화를 한 번에 수령, 성당 최대 8시간분)
- **가로 슬라이드**: 공용 컴포넌트 `HSlide`(`src/components/ui.tsx`) + CSS `.hslide` (`index.css`). 보유 장수는 2줄, 장비는 부위별 1줄. 스크롤바 숨김, 마우스 환경(`hover:hover` · `pointer:fine`)에서만 좌우 화살표, 폰은 터치 스와이프. 도전 탭도 `FormationEditor` 공용이라 함께 적용
- **도전 버튼**: `Challenge.tsx`에서 출진 패널을 적 패널 위로, "N층 도전!" 버튼을 패널 맨 위로
- **등용 사진**: `Missive`의 `GeneralToken`을 `size="fill"`로 크게, `.missive .sheet` 높이 확대 (다중 19rem / 단일 23.5rem)
- **등급 색**: `meta.ts`의 `RARITY`에 `badge` 색(SSR 금 · SR 보라 · R 회청)과 `ring` 추가, `GeneralToken` 테두리에 링 적용
- **모바일 군령 시트**: ✕ 버튼(`lg:hidden`), 처음엔 닫힘(`sheet` 상태), 성을 누르면 열림. 시트가 닫히면 아래 여백도 줄임. 페이지는 맨 위에서 시작

## 함정 · 교훈 (다음에 같은 실수 금지)

- `scrollIntoView`는 `overflow:hidden` 조상(지도 틀 `.war-map`)의 내부 스크롤까지 움직여, 맨 위 성(1-1)의 메달이 틀 밖으로 잘렸다. 창만 움직일 땐 `window.scrollTo`를 쓰고, 지도 틀은 `overflow-clip`
- 브라우저 점검 시 `html`의 `scroll-behavior: smooth` 때문에 `scrollTo` 직후 측정값이 어긋난다 → 측정 전 `scrollBehavior='auto'` + 대기
- PowerShell에서 백틱·`${}` 이 문자열에서 사라진다 → 편집은 StrReplace 도구나 작은따옴표 here-string. `R`은 `Invoke-History` 별칭
- `git push`의 stderr가 NativeCommandError처럼 보여도 성공이다 → `gh run list` / `gh run watch <id> --exit-status`로 확인
- 타입 검사는 `npm run build` (`tsc -p tsconfig.app.json` 직접 호출은 실패)
