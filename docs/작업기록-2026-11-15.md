## 기능 · 상태 요약

### 장수 초상 / 전신
- 상반신: `public/portraits/<id>.webp` + `PORTRAIT_IMAGES`
- 전신: `public/portraits/<id>-full.webp` + `PORTRAIT_FULL_IMAGES` (초상 있는 100명 전부)
- 상세 팝업: 초상 클릭 → 전신 전체화면 (`General.tsx` · `createPortal`)
- 비율 기준: **등애 전신** 정도가 적당. 너무 긴 패션 크로키(9등신)는 쓰지 말 것
- 생성: bust를 reference로 GenerateImage(3:4) → `sharp-cli` webp quality 82

### 경제 · 등용
- 유료 등용: 1회 100 / 10연 900 (무료 잔여가 있으면 먼저 소모)
- **매일 무료 10회** 자동 지급 (`freePulls` · `freeGrantDay`)
- **출석**: 하루 1회, 연속 시 추가 무료 (1·1·2·2·3·3·5, 7일 순환). 하루 비우면 연속 리셋
- 로직: `src/engine/attendance.ts` · UI: 등용 탭 상단
- 원정 `stages.ts` · 토벌 `conquest.ts` 금화 보상은 이전 대비 약 절반

### 편성 · UI
- 편성 포인트 → **금화** (저장/불러오기 비용, 맞춤 편성 200금, 실패·취소 시 환급)

- `Modal`은 반드시 body 포털 — PC sticky/overflow 패널 안에서 `fixed`가 깨지던 문제 재발 주의

### 저장
